Frame + Auto Clicker

Target: none · Clicks: 0
How it works / limits / relay list Runs a timer that fires real mouse events at the chosen spot. The browser does not allow those events to reach a site loaded from another domain inside the frame, so the clicker can only hit things on this page (like the test button), an HTML file you loaded with "Load HTML file", or a page opened with "Via proxy". Those run as part of this page. That is a browser security rule, not a bug. For anything else use the ChromeOS dwell click: Settings → Accessibility → Cursor and touchpad → Automatically click when the cursor stops.
"Refused to connect" inside the frame means that site forbids being framed. "Via proxy" downloads the page through one of the relays below (a public service that adds the permission this page needs to read it), rewrites it so its images and scripts still load from the real site, and puts it in the frame as part of this page. Nested game frames are pulled through the same way. Relays are third-party services: they may be slow, rate limited, offline, or blocked by a filter. Pages that need you to be logged in, or that talk to their own server from script, usually will not work through it. The relay list lives in Settings.
Drag and drop an .html file onto the frame to load it. Press F12 or Ctrl+` for the console.
Settings are saved in this browser only.
